1. Resumo do Conceito
O VibeFinance AI é um assistente de gestão financeira preditiva. O foco não é apenas o registro de gastos passados, mas o uso de Machine Learning e LLMs para prever o saldo futuro e oferecer mentorias personalizadas de economia, ajudando o usuário a alcançar metas de curto e longo prazo com precisão.

2. Meu Prompt Final (PRD)
Usei este prompt estruturado para guiar a IA na criação da lógica e interface:

"Atue como um Product Manager e Tech Lead. Crie um PRD para um App de Finanças Pessoais com IA. O app deve ter:

Dashboard com saldo real vs. projetado para 30 dias.

Categorização automática de transações via NLP.

Um Chatbot Mentor que sugere cortes de gastos baseados em metas de investimento.
Tech Stack sugerida: Next.js, Tailwind, Supabase e OpenAI API. O design deve ser Dark Mode com estética Cyberpunk/Minimalista."
